    How it works

    Every check below is a paid query to a live Telegraph miner. Shield never fabricates data — each answer arrives from the network with its own cost, latency and, when the engine issues one, a signal hash you can verify independently.

    GAS_PRICE

    Gas conditions

    A live miner reports current fee conditions on the target chain, so the agent never signs into a fee spike.

    ONCHAIN_TX_LOOKUP

    On-chain facts

    Canonical transaction facts read from real chain state — the same check that verifies a mined transaction hash.

    CRYPTO_PRICE

    Price context

    A live market price anchors the dollar value of what is about to move, before it moves.

    TVL_LOOKUP

    Protocol health

    When a protocol is named, its reported TVL helps flag drained or suspicious targets.

    Verdicts are advisory — the final signing decision stays with the agent. Responses carrying a signal hash can be checked against the Telegraph explorer.
