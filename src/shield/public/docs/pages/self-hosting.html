Self-hosting.

Clone the repository, put your keys in .env, and run npm run shield: the desks, the API and these docs come up on port 8788. Without a Telegraph key Shield still serves pages and memos, but cannot buy answers.

Run it

git clone https://github.com/mrnetwork0001/Truvian && cd Truvian
npm install
cp .env.example .env        # then fill in the keys you have
npm run shield              # Shield: desks, API, docs     (port 8788)
npm run dev                 # the miner                    (port 8787)
npm run truth               # the truth API                (port 8790)

Deploying

truvian.xyz runs Shield under pm2 behind nginx: deploy/ecosystem.shield.config.cjs and deploy/nginx-shield.conf; the miner has deploy/ecosystem.config.cjs and deploy/nginx-miner.conf. A deploy is git pull --ff-only, npm install when dependencies change, and a restart of that one pm2 app. Things that will bite you: public RPC endpoints change within days (run npm run test:miner before trusting the chain list), the Telegraph registry contract moves without notice (check it before any transaction), and a client IP is only right when nginx forwards it and SHIELD_TRUST_PROXY is on.
