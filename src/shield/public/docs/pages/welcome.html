Welcome to Truvian.

Truvian decides before money moves: it buys evidence from Telegraph's ranked specialist miners, checks every answer against the chain, and returns a signed memo with the cost and a receipt for each answer. It was built for Telegraph Protocol's Season II hackathon and runs on Telegraph's devnode today.

An agent, an exchange, a fund or a custodian that is about to act on a token, a payment or a market outcome usually trusts one source. A model can say a rug pull is "Secure"; a single oracle can be wrong; an issuer can overstate what it holds. Truvian asks the specialists, reads the chain itself, applies fixed public rules, and refuses to clear anything on an answer nobody checked. Every decision is a memo anyone can re-verify.

  • Shield desks - five decision desks for trading agents, listing desks, funds, custodians and prediction markets.
  • Miner - Telegraph registration 6180, answering six onchain intents on 14 EVM chains and Solana.
  • Evaluators - two champion adapters that judge other teams' miners on Telegraph.

The stack, in one paragraph

Everything is TypeScript on Node.js, run with tsx. The Shield server is Fastify 5 (src/shield/server.ts) serving the desks, the API and these docs from src/shield/public as plain HTML, CSS and vanilla JavaScript, with no framework or bundler. EVM chain reads use viem 2; Solana reads, devnet settlements and memo anchors use @solana/web3.js 1.99 and @solana/spl-token 0.4. Telegraph answers are bought through the node's engine route and paid from an Anjoman escrow; visitors past the free runs pay Shield over x402 with a gasless USDC signature. Memos are hashed with SHA-256 over canonical JSON and signed under EIP-191 (src/shield/memo.ts). The miner (src/miner) is a separate Fastify app. Keys live only in the server's .env: TELEGRAPH_API_KEY, TELEGRAPH_PAYER_KEY, SHIELD_MEMO_KEY, SOLANA_DEVNET_KEY. They are never sent to the browser or written into a memo.

Reading order

TestnetTelegraph Season II runs on testnet. Answers are paid in test USDC from an escrow on Ethereum Sepolia; Shield's own price is test USDC on Base Sepolia; settlements and anchors are on Solana devnet in test tokens. None of it has monetary value. The facts checked (token supply, pools, sanctions lists, registries, market outcomes) are real. Truvian is an independent hackathon entry.
