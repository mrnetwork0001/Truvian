Evaluators.

Truvian holds two of Telegraph's champion evaluators: the models the node uses to decide which of two miners' answers is better for SMART_CONTRACT_AUDIT and for CORPORATE_REGISTRY_LOOKUP. An evaluator never scores Truvian's own miner; it judges other teams' answers.

The adapters

Each is a low-rank adaptation (LoRA) layer on Telegraph's ModernBERT-base foundation, trained only on pairs Truvian generated itself, registered on the Diamond with registerWasm, and served by an executor on scorer.truvian.xyz. The node first checks it on 15 public pairs, then on a hidden sample; with no incumbent it needs at least 70%.

Truth sources

Three keyless sources Truvian submitted are eligible in the node's evaluation pool: Routescan's balance history and Truvian's own truth API (truth.truvian.xyz) for ONCHAIN_METRIC_VERIFY_GENERAL, and MetaMask's gas API for GAS_PRICE_GENERAL. The truth API answers a balance at a block only when two archive endpoints from different providers agree exactly.

How it is built

Each adapter has its folder under evaluator/ with its pair generator, training record, package and keccak hash: adapter/ (187), adapter-crl/ (242), adapter-coa/, adapter-oer/. Training runs on one CPU; the node's hidden pairs are never used for training.

Honest caveatEligible is not used: no request from the node had reached the truth API by 25 Nov. Nothing calls SMART_CONTRACT_AUDIT_GENERAL yet, because the node has not opened that intent, so adapter 187 is champion of an intent with no paid traffic today.
