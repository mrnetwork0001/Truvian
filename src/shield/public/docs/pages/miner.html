The miner.

Truvian's miner is Telegraph registration 6194 (6180 until 25 Nov): an HTTP API that answers six onchain intents from direct chain reads, with exact figures and no guesses. It runs at miner.truvian.xyz; the node sends it questions and scores its answers against a reference each epoch.

What it answers

RouteIntentScored field
/txONCHAIN_TX_LOOKUP_GENERALblock_number
/gasGAS_PRICE_GENERALgas_price_gwei
/balanceWALLET_BALANCE_CHECK_GENERALbalance
/total-supplyTOKEN_TOTAL_SUPPLY_VERIFY_GENERALtotal_supply
/transferCRYPTO_TRANSFER_VERIFY_GENERALno response format yet: judged on the answer text
/liquidityLIQUIDITY_DEPTH_VERIFY_GENERALliquidity_usd

It reads 14 EVM chains (Base, Ethereum, Arbitrum, Optimism, Polygon, BSC, Avalanche, Scroll, Linea, Gnosis, zkSync Era, X Layer, Sepolia and Base Sepolia; src/config/chains.ts). Since 25 Nov 2026 it also answers Solana mainnet and devnet: wallet balances summed over every token account (Token and Token-2022), mint supply, and transfers by signature, read at finalized from two providers that must agree (src/miner/solana.ts). Pool liquidity comes from the pool's on-chain reserves, checked against GeckoTerminal.

Try it directly, free: /gas?chain=base, /balance?address=vitalik.eth&chain=ethereum. These are diagnostic requests, not the node's scored questions.

How it is built

A Fastify app (src/miner/server.ts, npm run dev, port 8787) described to the node by telegraph/truvian-miner.yaml. Registration is one transaction to the Telegraph registry contract (the Diamond, 0x72a70e94…a08b on Ethereum Sepolia) with a test-USDC bond. npm run test:miner runs the live checks.

Updated 25 NovThe node builds each miner's request from its registered description. Registration 6180's described only EVM chains and 0x addresses, so Solana balance questions never reached us. On 25 Nov updateMiner (tx 0xa4924481…01f8) registered the description that adds Solana as registration 6194, active the same hour. A Solana devnet balance asked through the node and pinned to this miner came back right (998 tUSD, $0.01 receipt). A new registration spends 7 days in the grace period before it is ranked, so routed asks may still go to other miners first.
