Token preflight.

A trading agent asks "may I buy $1,000 of this token through this pool?" and gets HOLD, REVIEW or REJECT in a signed memo. This is Telegraph Mission 14 (Web3 Native and DeFi). The buy itself is simulated: Shield never trades.

How to use it

Open /preflight?desk=trade, pick a fixture under Try one or type your own, and press Run preflight. Agents call POST /api/preflight with the same fields.

FieldWhat it isNotes
mode"trade"required
chainethereum, base, arbitrum, optimism, polygon, bsc or avalanchethe chain list in the page; the server accepts any chain in src/config/chains.ts
tokenthe token contract, 0x plus 40 hex charactersrequired
poolthe DEX pool the trade goes throughrequired for a trade
tradeUsdthe simulated trade size in USDcompared with the pool's depth

What it buys

After reading the contract itself at one block (code, name, symbol, decimals, totalSupply(), proxy slots, owner()), Shield buys four facts, $0.01 each:

FactTelegraph intentChecked against
Security reviewSECURITY_REVIEW_GENERALwhether the answer examined this token at all
Total supplyTOKEN_TOTAL_SUPPLY_VERIFY_GENERALShield's totalSupply() read, 50 bps tolerance
Wash tradingWASH_TRADING_DETECTION_GENERALwhether trades were examined and the figure measured
Pool depthLIQUIDITY_DEPTH_VERIFY_GENERALthe trade size

SECURITY_REVIEW_GENERAL stands in for SMART_CONTRACT_AUDIT_GENERAL, which the node has not opened. Truvian's adapter 187 is already that intent's champion evaluator.

The rules

FindingSeverityWhen
chain.not_a_contractblockthe address has no contract code
security.honeypot, security.insecureblockthe review says the token cannot be sold, or is insecure
wash.blockblockwash trading at or above 50% of volume
security.not_examined, security.not_about_token, security.no_verdictreviewthe review examined nothing, was about another token, or gave no verdict
supply.conflictreviewTelegraph's supply is more than 50 bps from the chain read
wash.review, wash.not_examined, wash.not_measuredreview20% to 50% wash, or a figure from an answer that saw no trades
liquidity.thin, liquidity.price_impactreviewpool under $100,000, or the trade above 1% of it
security.holder_concentrationreviewtop 10 holders over 50%, unless the pool holds at least $1,000,000
buy or sell taxreview / blockat or above 10% / 50%
a missing answerreviewany fact without an answer: nothing is cleared on a missing check

Any block gives reject; otherwise any review gives review; only a clean set gives hold. The thresholds are written into every memo (POLICY in src/shield/preflight.ts).

How it is built

runPreflight in src/shield/preflight.ts plans the asks, buy buys each fact once (with reuse and a second opinion, withSecondOpinion), and evaluate turns reads and answers into findings and the decision. Chain reads are readTokenFacts in src/shield/tokenFacts.ts. The signed memo comes from signMemo in src/shield/memo.ts. npm run test:preflight replays stored answers through the rules.

Honest caveatSince 22 Nov 2026 routed SECURITY_REVIEW_GENERAL asks have mostly ended in a gateway timeout, so most preflights end in REVIEW: a missing security review cannot clear a token. Shield does not retry a timeout (it would pay twice), and the decision says why.
