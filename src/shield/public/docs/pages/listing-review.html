Listing review.

An exchange's listings desk checks a token, its issuer and its treasury, and gets LIST, REVIEW or REJECT. This is Telegraph Mission 01. It runs every token check of the preflight, then screens the issuer and matches the treasury to the chain.

How to use it

Open /preflight?desk=listing or call POST /api/preflight with mode: "listing".

FieldWhat it isNotes
chain, tokenas in the token preflightrequired
poola DEX pool for the tokenoptional; its liquidity is bought too
issuerthe issuer's legal namescreened with SANCTIONS_SCREENING_MATCH_GENERAL
treasurythe issuer's treasury walletoptional; its native balance is read and bought

The extra rules

FindingSeverityWhen
sanctions.matchblockthe issuer's name matched a sanctions list
sanctions.near_matchreviewno match, but a fuzzy score of 0.85 or more: a person compares the names
sanctions.uncertainreviewno clear match result
treasury.conflictreviewTelegraph's treasury balance is more than 5 bps from Shield's read at the same block
treasury.chain_onlyinfothe balance intent (ONCHAIN_METRIC_VERIFY_GENERAL) covers Ethereum, Polygon and Arbitrum only, so on other chains the chain read stands alone

Plus every token rule from the token preflight. The clean decision is list.

How it is built

The same runPreflight with mode: "listing": sanctionsFindings and treasuryFindings in src/shield/preflight.ts add the issuer and treasury checks, and the treasury is read a few blocks back so every provider's node has it (readBalanceGwei).
