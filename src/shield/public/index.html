The desks

One engine, one decision per desk.

Each desk reads the chain itself, buys the facts it cannot read through Telegraph, applies fixed rules and signs the result. Five free runs a day per IP; nothing to install, no wallet needed to look.

How it works

Read, buy, rule, sign.

  1. 1 · Read

    The chain first, for free

    Shield reads what the chain can answer itself: the token contract or Solana mint, balances, supply, authorities. Solana mainnet reads go to two RPC providers that must agree.

  2. 2 · Buy

    One paid ask per fact

    What the chain cannot say (a security review, a sanctions screen, a registry record, an independent balance) is one routed ask to Telegraph, paid from escrow with a receipt. When an answer is no evidence, one more ask goes to the next-best ranked miner.

  3. 3 · Rule

    Fixed, public rules

    The same evidence always gives the same decision. An unanswered check, an answer about the wrong address, or a figure that disagrees with the chain can never clear anything.

  4. 4 · Sign

    A memo anyone can check

    The decision, findings, receipts and cost are hashed and signed under EIP-191. Each memo has a permalink, a JSON download and a free POST /api/memo/verify.

For agents

One POST, one signed decision.

Same endpoint for every desk; mode picks the desk. Add ?stream=1 for newline-delimited events as each answer lands. Five free runs per IP a day (reset 00:00 UTC), then $0.05 in test USDC on Base Sepolia over x402: one EIP-3009 signature, settled only after the work succeeded.

# trading agent: may I buy $1,000 of WETH through this pool?
curl -s https://truvian.xyz/api/preflight \
  -H 'content-type: application/json' -d '{
  "mode": "trade", "chain": "ethereum",
  "token": "0xC02aaA39b223FE8D0A0e5C4F27eAD9083C756Cc2",
  "pool":  "0x88e6A0c2dDD26FEEb64F039a2c41296FcB3f5640",
  "tradeUsd": 1000 }'

# custodian: may I pay this counterparty on Solana?
curl -s https://truvian.xyz/api/preflight \
  -H 'content-type: application/json' -d '{
  "mode": "settlement", "network": "solana-devnet",
  "mint": "TUSD", "amount": "1",
  "recipient": "Afb8MYs9G63oHAPkZiK6cb5JKzuWy9is3pHc6Zj5voYZ",
  "counterparty": "Coinbase Global, Inc.",
  "jurisdiction": "US-DE", "execute": false }'

Limits

What is not true yet.

  • Testnet money. Telegraph answers are paid in test USDC from an Anjoman escrow on Ethereum Sepolia; Shield's own charge is test USDC on Base Sepolia; settlements are sent on Solana devnet in test tokens. Token facts are read from mainnets.
  • Security reviews time out. Since 22 Nov every routed SECURITY_REVIEW ask has ended in a gateway timeout, so token preflights and listing reviews usually end in REVIEW: nothing is cleared on a missing answer.
  • Solana balances. On 25 Nov no miner on the node answered a Solana wallet balance. Ours now does; until the node routes those questions to it, the settlement desk's funds check rests on its own two-provider chain read.
  • Prediction-market resolution is in progress, not live.
  • The Season I pre-sign check is still online at /app; it is looser than the desks and keeps its Season I wording.
